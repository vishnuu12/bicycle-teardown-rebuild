# Bicycle Teardown & Rebuild

A **single-file static documentary** that explains every part of a bicycle — what it is,
why it exists, what it connects to, and how each part supports the next (the one-to-one
support chain) — and then walks through a full teardown and rebuild.

Bilingual: **Tamil + English** (Tamil script for explanations, English for technical terms).

## Live site

GitHub Pages: `https://vishnuu12.github.io/bicycle-teardown-rebuild/`

## Run locally

Just open `index.html` in any browser. No build step, no dependencies, works fully offline.

## What's inside

- **Anatomy Map** — interactive SVG bicycle. Click any part to see its job. *Dismantle* and
  *Rebuild* buttons animate the parts off and back on in the correct order.
- **One-to-One Support Chain** — five dependency chains (Power, Steering, Stopping, Body, Ground).
- **Teardown & Rebuild Order** — the safe removal sequence (frame comes last).
- **Every Part, One by One** — 16 parts, each with what/why/connects/supports/supported-by,
  plus dismantle, rebuild, tip and common-mistake notes.
- **Tools, Glossary & Common Mistakes.**

## Parts covered

Frame, Fork, Headset, Stem + Handlebar + Grips, Brakes & Levers, Wheels (Rim/Spokes/Hub),
Hub & Freehub, Tire & Tube, Crankset & Chainring, Bottom Bracket, Pedals, Chain, Cassette,
Derailleurs, Shifters & Cables, Saddle + Seatpost + Clamp.

## Tech

Pure HTML + CSS + JavaScript in one file. No frameworks. System fonts only — nothing is
fetched from the network, so it renders identically offline.
